# 🌿 Namma-Hasiru – Smart Plantation Tracker

## 📌 Overview
Namma-Hasiru is a Smart Plantation Tracker Android application developed using Kotlin and GenAI-assisted Android development.

The app helps users:
- track plantation drives,
- geo-tag plantation locations,
- monitor sapling survival,
- receive follow-up reminders,
- and analyze plantation success rates.

---

## 🚀 Features

- Add New Plant
- Plant Photo Capture
- GPS Geo-tagging
- RecyclerView Plant Listing
- Survival Dashboard
- WorkManager Notifications
- Google Maps Integration
- Material Design 3 UI

---

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- XML Layouts
- Room Database
- RecyclerView
- WorkManager
- Google Maps SDK
- Material Design 3
- ViewBinding
- FileProvider

---

## 🌍 Purpose

The project aims to convert plantation drives into a long-term sustainability tracking system.
